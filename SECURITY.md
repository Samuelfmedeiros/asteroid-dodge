# Security Policy

## Supported Versions

This project is a public repository for educational/portfolio purposes.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it by opening a [GitHub Security Advisory](https://github.com/Samuelfmedeiros/asteroid-dodge/security/advisories/new).

Please do **not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

You should receive a response within 48 hours. If for some reason you do not, please follow up via email to ensure we received your original message.

## Responsible Disclosure

We kindly ask that:
- Give us a reasonable time to investigate and fix the issue before disclosing it publicly
- Provide sufficient details to reproduce the issue
- Do not access or modify other users' data without permission

Thank you for helping keep this project and its users safe.
